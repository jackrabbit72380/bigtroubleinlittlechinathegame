
On GitHub: open the folder you want, click **Add file** then **Upload files**,
drag the images in, and commit to `main`. Then say "uploaded".

jpg, png and webp all work. No renaming, cropping or resizing needed - a
readable name like `a-pose.png` or `clay-front.png` just helps me tell them
apart.

For fighters, what helps most:

* one full-body colour picture with the boots in the frame
* the untextured grey front view (clean edges)
* the grey side view (depth)
* close-ups of anything that matters (boots, head, weapons, the shirt graphic)

For UI, what helps most:

* a full-screen mock-up of a match (health and power bars, timer, names)
* the select screen grid and any character portraits
* win screen / continue screen layout
* title logo and menu buttons
* the exact colours, fonts and glow you want, as screenshots of anything you like

Drop them straight into `ui/` - no subfolders needed, and file names like
`lifebar.png` or `select-screen.jpg` are plenty.
