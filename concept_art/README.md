# Concept art drop

Put Jack Burton's concept images in THIS folder.

While you are inside this folder on GitHub, click **Add file** then
**Upload files**, drag the images in, and commit to `main`.

Then tell me "uploaded" and I will pull them straight into the project and cut
them into the rig parts.

What helps most:

* one full-body colour picture with the boots in the frame
* the untextured grey front view (clean edges)
* the grey side view (depth)
* the boot close-ups

jpg, png and webp all work. No renaming, cropping or resizing needed.
