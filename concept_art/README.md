# Concept art drop

Put Jack Burton's concept images in THIS folder - the one you are looking at.

Just copy or drag the image files here (jpg, png, webp - all fine). Nothing else
is needed: no renaming, no cropping, no resizing.

What helps most:

* one full-body colour picture with the boots in the frame
* the untextured grey front view (clean edges)
* the grey side view (depth)
* the boot close-ups

Then tell me "they're in" and I will cut them into the rig parts.
