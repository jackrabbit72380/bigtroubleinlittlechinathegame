# Jack Burton - source art

Drop the full-body concept art in this folder as PNG or JPG, then tell me and I
will cut it into the rig parts in `../parts/`.

**Preferred input:** one full-body COLOUR frame, whole figure in shot including
the boots - nothing cropped at the feet. Arms down or in an A-pose both work:
each part takes a rest angle, so art drawn with the arms out still bends right.

Suggested filenames (any names work, these just tell me which is which):

| file | what it is |
|---|---|
| `a-pose.png` | colour, arms out, pistol in hand - main paint source |
| `clay-front.png` | untextured front, arms down, boots visible - clean edges |
| `clay-side.png` | untextured side profile - depth for shading the limbs |
| `gun-raised.png` | colour, pistol raised - grip and shoulder reference |
| `boots.png` | boot references - shaft, straps, welt, tread |

Anything extra you have (head close-up, the shirt graphic, the knife) is useful
too. Nothing here is committed to the game until the parts are cut and built.
