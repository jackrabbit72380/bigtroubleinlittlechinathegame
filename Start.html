Big Trouble in Little China

update & play

This page is for updating a copy you already play. Everything here is a normal browser download, so it works even when a proxy or antivirus blocks the little black command window.

Install the newest build

  1. Download the game files — about 190 MB, saves as a zip.
  2. Put that zip in your game folder — the folder with BigTroubleInLittleChinaTheGame.exe in it. Leave the name as it arrives.
  3. Download the applier below into the same folder, then double-click it.
Download the game files (.zip) Download Apply main.zip.bat

The applier has no download code in it. It unpacks the zip, copies data, chars, stages, font, external and sound over your folder, leaves your save and the engine alone, and starts the game. Nothing in it can hang.

If you would rather have one click

Use the updater instead. It fetches only what changed when Git works, counts the megabytes while it downloads, and starts the game when it is done. If every download route is blocked it opens the zip in this browser and finishes the update by itself as soon as the file lands in Downloads.

Download Update and Play.bat
How to tell it worked. The top of the screen in a match is the dragon strip — its back is health, its belly is audacity, its head turns in to the yin-yang timer. Pause during a match and there is a Developer Keys entry that opens the shortcut list. The applier prints HUD : dragon before the game starts.

Two things that trip people up

  • Browsers often save a .bat as .bat.txt. Rename it so it ends in exactly .bat, and turn on file name extensions in Explorer if you cannot see them.
  • Windows may block a downloaded script: right-click it, choose Properties, tick Unblock, then run it.
